## Verify all at once
```
cd verify && node verify-all.mjs    # all folders vs Base Sepolia
RPC_URL=<url> node verify-all.mjs   # or against a fork / local node
```

`verify/` is self-contained: its own local `ethers`, and the golden reference bytecode stored next to each contract. It resolves proxies, normalizes library links + the `__self` immutable, strips metadata, and prints a per-contract verdict.

## Method
`verify/verify-bytecode.mjs <address> <artifact.json> [--impl]`:
1. `eth_getCode(address)` on Base Sepolia.
2. If `--impl`, resolve the EIP-1967 implementation slot and verify the impl.
3. Re-link external libraries (from `deployedLinkReferences`, addresses read from on-chain) + normalize the `__self` immutable.
4. Diff against the artifact's `deployedBytecode`, exact and modulo-metadata.

Plain contracts (verifiers) were also **fresh-compiled** with the exact deploy solc (0.8.28 for passport-contracts, 0.8.23 for the TD1 verifier).

## Compiler settings
- `passport-contracts` / `passport-voting-contracts`: solc **0.8.28**, optimizer **runs 200**, evm **london**.
- TD1 verifiers (`td1-research`): solc **0.8.23**, `--optimize` (runs 200), evm **shanghai**.
- `IdeaRegistry`: solc **0.8.33**.

## Transitive deps
Used internally by the above but not named in the gateway/app configs. All resolved *live* from the contracts that point at them and checked byte-for-byte (read-only) `9/9 confirmed`:
- **Voting query verifiers** — TD3 `BioPassportVotingVerifier` (23 signals) + TD1 `QueryIdentityTD1Verifier` (24) — **EXACT** (security-critical; a rogue verifier breaks the ZK guarantee).
- **ProposalSMT** (impl; ProposalsState clones one proxy per proposal) — **EXACT**.
- **CertificatesSMT** (PoseidonSMT proxy) + **MockEvidenceRegistry** (no-op stub) — **EXACT**; deployed but not used in PoC.
- **Poseidon libraries** — voto set = circomlibjs; registro set = poseidon-solidity wrappers → shared `PoseidonT2/3/4`.

```
cd transitive && node verify-transitive.mjs   # 9/9 (wiring + bytecode)
```
